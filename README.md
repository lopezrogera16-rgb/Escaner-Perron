# ESCANER PERRON DE PIXELES DE IMAGEN :D
Unos se preguntan **"¿Cuanto Mide Mi Imagen?"** Este programa pequeño resuelve esa duda :D
Pon la ruta de la imagen  y te suelta el ancho y alto YEEEEYY :D

## Como se Usa?
1. Descarga el .jar desde *[Releases]*
2. Abrelo con doble click o:
    `java -jar "Escaner De Pixeles.jar"` 
3. Pega la ruta de tu imagen chilera
4. Te sale Una ventanita que te dice el ancho y alto :D

## Que Necesitas
Java 21 o más reciente (Hecho Con OpenJDK 21)

## El Codigo
Son 2 `.java`, uno hace la logica y el otro la llama
**Logica**: `EscanerDePixeles.java`
**El que lo llama**: `Main.java`
Si Truena el programa, posiblemente pusiste mal la ruta :c
